# DMA 완료 ISR 집계 (P2_110M_off, N=1000)

원자료 `results/isr/P2_110M_off_its{0..5}/*.csv`. 방법은 `cmpISRoverhead.md` §12. 값은 사이클, 중앙값 (min/avg/max).

## 1. 구간 전체: TC pending 직후 ~ NS ISR 복귀 (k=0 빌드)

| 경로 | ISR = t1−T0−CAL | CAL (min) |
|---|---|---|
| S (Secure DMA, CH1 + doorbell) | 573 (573/579.3/991) | 26 |
| N (Insecure DMA, CH2) | 505 (505/508.7/923) | 26 |
| **S − N** | **+68** (1.13x) | |

## 2. 구간 분해 (중앙값끼리의 차)

| 구간 | S | N | S − N | 스탬프 |
|---|---|---|---|---|
| HW 진입 (NS→S) | 20 | 14 | +6 | T0 → Ta (N: T0 → Tn) |
| Secure ISR 본문 | 86 | — (없음) | +86 | Ta → Tb |
| Secure 퇴장 + tail-chain | 14 | — (없음) | +14 | Tb → Tn |
| NS prologue | 7 | 12 | -5 | Tn → Tc |
| NS 본문 | 434 | 462 | -28 | Tc → Td |
| NS epilogue + HW 복귀 | 12 | 17 | -5 | Td → t1 |
| **합** | **573** | **505** | **+68** | = 구간 전체 |

스탬프 지점 P_k = median(Tk−T0) − CAL(k):

| 지점 | S | N |
|---|---|---|
| k=1 Ta | 20 | — (없음) |
| k=2 Tb | 106 | — (없음) |
| k=3 Tn | 120 | 14 |
| k=4 Tc | 127 | 26 |
| k=5 Td | 561 | 488 |

## 3. 검증

| 항목 | 값 | 판정 |
|---|---|---|
| S: 0 < P_k 증가 < ISR | 20, 106, 120, 127, 561 < 573 | OK |
| N: 0 < P_k 증가 < ISR | 14, 26, 488 < 505 | OK |
| CAL 표 열1 = 0 (보정 중 ISR 미실행, 전 빌드) | 최대 0 | OK |
| k=1,2 isr_n 열1 = 0 (N 경로는 Secure ISR 미실행) | 최대 0 | OK |
| CAL S ≈ N (같은 구간 명령) | 26 vs 26 | OK |
