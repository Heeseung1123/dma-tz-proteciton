# DMA 완료 ISR 집계 (P2_110M_warm, N=1000)

원자료 `results/isr/P2_110M_warm_its{0..5}/*.csv`. 방법은 `cmpISRoverhead.md` §12. 값은 사이클, 중앙값 (min/avg/max).

## 1. 구간 전체: TC pending 직후 ~ NS ISR 복귀 (k=0 빌드)

| 경로 | ISR = t1−T0−CAL | CAL (min) |
|---|---|---|
| S (Secure DMA, CH1 + doorbell) | 273 (263/274.7/537) | 9 |
| N (Insecure DMA, CH2) | 241 (241/242.1/450) | 9 |
| **S − N** | **+32** (1.13x) | |

## 2. 구간 분해 (중앙값끼리의 차)

| 구간 | S | N | S − N | 스탬프 |
|---|---|---|---|---|
| HW 진입 (NS→S) | 12 | 12 | +0 | T0 → Ta (N: T0 → Tn) |
| Secure ISR 본문 | 38 | — (없음) | +38 | Ta → Tb |
| Secure 퇴장 + tail-chain | 7 | — (없음) | +7 | Tb → Tn |
| NS prologue | 3 | 4 | -1 | Tn → Tc |
| NS 본문 | 200 | 241 | -41 | Tc → Td |
| NS epilogue + HW 복귀 | 13 | -16 | +29 | Td → t1 |
| **합** | **273** | **241** | **+32** | = 구간 전체 |

스탬프 지점 P_k = median(Tk−T0) − CAL(k):

| 지점 | S | N |
|---|---|---|
| k=1 Ta | 12 | — (없음) |
| k=2 Tb | 50 | — (없음) |
| k=3 Tn | 57 | 12 |
| k=4 Tc | 60 | 16 |
| k=5 Td | 260 | 257 |

## 3. 검증

| 항목 | 값 | 판정 |
|---|---|---|
| S: 0 < P_k 증가 < ISR | 12, 50, 57, 60, 260 < 273 | OK |
| N: 0 < P_k 증가 < ISR | 12, 16, 257 < 241 | **확인 필요** |
| CAL 표 열1 = 0 (보정 중 ISR 미실행, 전 빌드) | 최대 0 | OK |
| k=1,2 isr_n 열1 = 0 (N 경로는 Secure ISR 미실행) | 최대 0 | OK |
| CAL S ≈ N (같은 구간 명령) | 9 vs 9 | OK |
