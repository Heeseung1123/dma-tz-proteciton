# DMA 완료 ISR 집계 (P2_32M_off, N=1000)

원자료 `results/isr/P2_32M_off_its{0..5}/*.csv`. 방법은 `cmpISRoverhead.md` §12. 값은 사이클, 중앙값 (min/avg/max).

## 1. 구간 전체: TC pending 직후 ~ NS ISR 복귀 (k=0 빌드)

| 경로 | ISR = t1−T0−CAL | CAL (min) |
|---|---|---|
| S (Secure DMA, CH1 + doorbell) | 283 (283/287.5/502) | 12 |
| N (Insecure DMA, CH2) | 252 (252/255.3/453) | 12 |
| **S − N** | **+31** (1.12x) | |

## 2. 구간 분해 (중앙값끼리의 차)

| 구간 | S | N | S − N | 스탬프 |
|---|---|---|---|---|
| HW 진입 (NS→S) | 13 | 13 | +0 | T0 → Ta (N: T0 → Tn) |
| Secure ISR 본문 | 46 | — (없음) | +46 | Ta → Tb |
| Secure 퇴장 + tail-chain | 9 | — (없음) | +9 | Tb → Tn |
| NS prologue | 2 | 4 | -2 | Tn → Tc |
| NS 본문 | 201 | 223 | -22 | Tc → Td |
| NS epilogue + HW 복귀 | 12 | 12 | +0 | Td → t1 |
| **합** | **283** | **252** | **+31** | = 구간 전체 |

스탬프 지점 P_k = median(Tk−T0) − CAL(k):

| 지점 | S | N |

| k=1 Ta | 13 | — (없음) |
| k=2 Tb | 59 | — (없음) |
| k=3 Tn | 68 | 13 |

## 3. 검증

| 항목 | 값 | 판정 |
|---|---|---|
| S: 0 < P_k 증가 < ISR | 13, 59, 68, 70, 271 < 283 | OK |
| N: 0 < P_k 증가 < ISR | 13, 17, 240 < 252 | OK |
| CAL 표 열1 = 0 (보정 중 ISR 미실행, 전 빌드) | 최대 0 | OK |
| k=1,2 isr_n 열1 = 0 (N 경로는 Secure ISR 미실행) | 최대 0 | OK |
| CAL S ≈ N (같은 구간 명령) | 12 vs 12 | OK |
