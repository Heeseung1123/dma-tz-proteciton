## DMA 배치 (NS SRAM, `s_dmaTaskMem`)

`sizeof(dma_task_globals_t)` = 12, `sizeof(dma_task_mem_t)` = 768, Cluster 오프셋 = 256, 총 1536 B @ 0x2001b500

```
0x2001b500  [A.globals  256 B : 사용 12 + 패딩 244]  NS-MPU r5 시작
0x2001b600  [A.cluster  256 B]  NS-MPU r5 끝 | S-MPU 영역 4
0x2001b700  [A.guard    256 B]  MPCBB Secure 블록 (NS-MPU 밖)
0x2001b800  [B.globals  256 B : 사용 12 + 패딩 244]  NS-MPU r5 시작
0x2001b900  [B.cluster  256 B]  NS-MPU r5 끝 | S-MPU 영역 5
0x2001ba00  [B.guard    256 B]  MPCBB Secure 블록 (NS-MPU 밖)
0x2001bb00  (끝)
```

Secure 리터럴(S-MPU RBAR BASE) 대조: A 0x2001b600 일치, B 0x2001b900 일치
